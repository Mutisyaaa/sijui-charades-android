# Sijui Charades (Android) 🇰🇪

Native **Kotlin + Jetpack Compose** Android app for **Sijui Charades** (*"Sijui"* = Swahili for *"I don't know"*), featuring:

- **🎭 Classic Charades (Heads Up! Style):** Quick Play & Team Battle, landscape forehead mode, native accelerometer tilt controls (tilt down = Correct, tilt up = Pass), offline Kenyan decks + live deck sync.
- **📸 Nani Huyu? (Who Am I? Multiplayer):** Real-time 4-letter room codes, custom Photo Studio packs, outward-facing forehead character cards, and live 🥇🥈🥉 Podium with Kenyan banter.

## Download the Android App
Download the latest signed APK from the **[Releases](../../releases/latest)** page:
1. Tap **`sijui-charades-v1.0.0.apk`** on your Android phone.
2. If prompted, allow **Install from this source** once.
3. Open **Sijui Charades** and play!

## Build Locally
```bash
./gradlew assembleDebug
```
> **Note:** Release signing secrets (`keystore/` and `keystore.properties`) are excluded via `.gitignore`.
